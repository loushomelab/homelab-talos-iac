## 后续交付与审批的具体内容

每个实施请求应先完成可审查材料，再请成员决定：

1. 目标对象、当前/目标版本、完整 PR SHA、字段/资源 diff、受影响服务和执行窗口。
2. 备份/数据覆盖、原数据保留、隔离目标、所需权限/敏感材料的安全引用与成本。
3. 每一步的写影响、超时/停止点、允许执行者、回退/补偿；明确哪些副作用不能用 Git 撤销。
4. 验收证据：source 精确版本、具体字段、真实 workload、端点/数据时间戳、对象/文件摘要及 RPO/RTO。
5. 失败处置和清理清单；切换生产作为独立决定，不因隔离环境通过自动放行。

故障演练。运行配置所在分支的合并可能触发 Argo/HCP 自动执行，审批前须把这一影响写清楚。
